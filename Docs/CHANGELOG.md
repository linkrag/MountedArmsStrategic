# Changelog - Mounted Arms: Strategic Missiles

Versioning: SemVer. 1.0.0 = first Steam Workshop publication (2026-11-07). MINOR = new feature, PATCH = fixes/tweaks. Before each Workshop upload, bump `<modVersion>` in `About/About.xml`, this file and the Changelog section of `Docs/WORKSHOP_DESCRIPTION.txt` together (player-facing text, English).

## 1.0.1 (2026-11-13)
- Missile recipes now step by 1 in the "Until X" bill count instead of 20.

## 1.0.0 (2026-11-07)
- Real-world launchers: M270 (ATACMS), M142 HIMARS, M777 howitzer, Mk 41 VLS (Tomahawk) and Minuteman III silo.
- Strike settlements on the world map from your colony using Combat Extended's world shelling, with accurate guided missiles.
- Large explosions use real overpressure zones: vaporized core and crater, damage rings, mountain bases act as shelters.
- Cluster, thermobaric and EMP warheads for ATACMS and Minuteman.
- MIM-104 Patriot battery intercepts incoming shells, missiles and drop pods (needs CE's Enable CIWS option).
- With Dubs Rimatomics: fission, W62 and W78 nuclear Minutemen with thermal pulse and fallout, plus the RS-28 Sarmat MIRV.
- Spacer, ultra and archotech factions retaliate with missiles; settings scale retaliation and, with Rimatomics, allow nuclear retaliation.
- Supports RimWorld 1.6 and 1.7; buildings use the Mounted Arms Military tab when that mod is active.
